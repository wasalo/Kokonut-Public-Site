# This page is a forecast model — not a record of achieved harvests or revenue.

Adelphi's crop model estimates how short-, medium-, long-cycle, and continuous production **could perform under a defined set of assumptions**.

It is useful for:

- planting and production planning;
- comparing crop timelines;
- estimating gross-revenue scenarios;
- testing loss and price assumptions;
- planning data collection;
- comparing forecasts with actual harvest records over time.

It is **not** a live farm ledger, profit-and-loss statement, guaranteed return, or record of realized revenue.

</Warning>

## How to read this model

The forecast combines crops that operate on different timelines.

That means the headline annual total is best understood as a **steady-state planning snapshot**, not a guaranteed single-calendar-year result.

| Stream | Forecast maturity |
| --- | --- |
| **Lettuce** | Short-cycle annualized model |
| **Passion fruit** | Medium-cycle annual production assumption after establishment |
| **Coconut** | Long-cycle annual production assumption at productive maturity |
| **Poultry eggs** | Continuous production estimate; revenue excluded because the pricing model is incomplete |

<Info>
  Coconut revenue should not be added to an early-year cash-flow expectation before the trees reach productive maturity. Likewise, passion-fruit and poultry performance should be reconciled against establishment and production records rather than assumed from the model.
</Info>

## Core calculation logic

The crop model starts from a simple production relationship:

```text
Gross Production
= Planting Density
× Planting Area
× Number of Production Units

Modeled Saleable Production
= Gross Production
× (1 − Loss Rate)

Modeled Gross Revenue
= Saleable Production
× Planning Price
```

For packaging-based crops such as passion fruit, an additional packaging step is required.

```text
Complete Sale Units
= floor(Saleable Individual Units ÷ Units per Package)

Modeled Gross Revenue
= Complete Sale Units × Price per Package
```

The **15% loss rate** is a model-wide planning assumption.

It should eventually be replaced by crop- and season-specific actual loss rates.

## Short cycle — lettuce

Lettuce is the largest modeled gross-revenue stream in the current forecast.

### Current variables

```text
Planting density:           12 lettuces/m²
Bed area:                   25 m²
Beds per plot:              19
Plots:                      10
Loss rate:                  15%
Production multiplier:      0.85
Modeled harvests per year:  5
Baseline planning price:    \$0.55/unit
Upside scenario price:      \$0.63/unit
```

### Production calculation

| Step | Calculation | Result |
| --- | --- | ---: |
| Plants per bed | `12 × 25` | 300 |
| Plants per plot | `300 × 19` | 5,700 |
| Gross plants across 10 plots | `5,700 × 10` | 57,000 |
| Modeled saleable units | `57,000 × 0.85` | **48,450/harvest** |
| Annual modeled units | `48,450 × 5` | **242,250/year** |

### Revenue calculation

| Scenario | Calculation | Modeled gross revenue |
| --- | --- | ---: |
| Baseline per harvest | `48,450 × \$0.55` | **\$26,647.50** |
| Upside per harvest | `48,450 × \$0.63` | **\$30,523.50** |
| Baseline annualized | `242,250 × \$0.55` | **\$133,237.50** |
| Upside annualized | `242,250 × \$0.63` | **\$152,617.50** |

### What is still an assumption

The repository currently describes:

- 30–45 days for loose-leaf lettuce;
- 60–75 days for head lettuce;
- 5 modeled harvests per year.

Those timing values belong to the current planning model and should be replaced or refined with Adelphi-specific crop-cycle actuals as records accumulate.

### What actuals should replace

- planted units;
- germination / establishment loss;
- field loss;
- harvest quantity;
- quality grade;
- rejected units;
- donated or consumed units;
- sold units;
- sale price;
- buyer/channel;
- harvest date;
- days from planting to harvest.

## Medium cycle — passion fruit

### Current variables

```text
Area per plot:                629 m²
Spacing:                      3 m × 3 m
Plants per plot:              70
Plots:                        8
Total plants:                 560
Gross yield assumption:       100 fruits/plant/year
Loss rate:                    15%
Modeled net yield:            85 fruits/plant/year
Package size:                 13 fruits/net
Planning price:               \$3.01/net
```

### Production calculation

| Step | Calculation | Result |
| --- | --- | ---: |
| Modeled saleable fruit | `85 × 560` | **47,600 fruits** |
| Complete 13-fruit nets | `floor(47,600 ÷ 13)` | **3,661 nets** |
| Loose remainder | `47,600 − (3,661 × 13)` | **7 fruits** |
| Revenue from complete nets | `3,661 × \$3.01` | **\$11,019.61** |

The existing forecast monetizes only complete nets.

It does not assign revenue to the seven-fruit remainder, nor does it model packaging cost, damaged fruit, direct-sale pricing, or different buyer channels.

### Actuals needed

- surviving vines;
- establishment date;
- fruit count per vine;
- harvest periods;
- grade/rejection rate;
- package size;
- packaging loss;
- realized sale price;
- buyer/channel;
- unsold or donated fruit.

## Long cycle — coconut

Coconut is the long-duration crop in the current planning model.

### Current variables

```text
Trees:                        96
Gross mature-yield assumption:75 coconuts/tree/year
Loss rate:                    15%
Modeled net yield:            64 coconuts/tree/year
Planning price:               \$0.79/coconut
Modeled first-harvest window: 3–5 years after planting
```

### Production calculation

| Step | Calculation | Result |
| --- | --- | ---: |
| Modeled annual units at maturity | `64 × 96` | **6,144 coconuts** |
| Modeled gross revenue | `6,144 × \$0.79` | **\$4,853.76/year** |

<Warning>
  This is a **maturity-stage annual model**. It should not be treated as year-one or near-term revenue. The 3–5 year first-harvest window and 75-coconut gross-yield assumption are current planning assumptions in the repository and should be reconciled against actual Adelphi tree records over time.
</Warning>

Potential derivative products—oil, milk, water, husk, fiber, or timber—are **not included** in the baseline revenue total.

If those become real commercial streams, they should have separate:

- processing assumptions;
- yield conversions;
- costs;
- prices;
- market evidence;
- actual sales records.

## Combined gross-revenue model

Using the current crop assumptions:

```text
Lettuce:        \$133,237.50
Passion fruit:   \$11,019.61
Coconut:          \$4,853.76
────────────────────────────
Crop total:     \$149,110.87

Poultry:        excluded from revenue total
```

This number should be described as **modeled gross crop revenue**.

It should not be called:

- net revenue;
- profit;
- cash available for distribution;
- household income;
- DAO income;
- guaranteed annual revenue.

Those require additional accounting data.

## Forecast → actual → revised forecast

The model should behave as a learning system.

```mermaid
flowchart LR
    A["Planning assumptions"] --> B["Forecast"]
    B --> C["Planting + farm operations"]
    C --> D["Harvest + sales actuals"]
    D --> E["Variance analysis"]
    E --> F["Updated crop-specific assumptions"]
    F --> G["Revised forecast"]
    G --> C

    D --> H["Kokonut Hub + MRV"]
    H --> E
```

For each cycle, the farm should be able to calculate:

```text
Production Variance
= Actual Production − Forecast Production

Price Variance
= Actual Price − Forecast Price

Gross Revenue Variance
= Actual Gross Revenue − Forecast Gross Revenue

Actual Loss Rate
= 1 − (Actual Saleable Production ÷ Gross Planted / Expected Production Basis)
```

The exact denominator for loss rate should be defined consistently by crop so different periods remain comparable.

## Minimum actuals dataset

To make this forecast genuinely operational, each harvest should preserve enough information to answer:

| Field | Why it matters |
| --- | --- |
| Farm / plot | Connects outcome to place |
| Crop / variety | Prevents unlike crops from being aggregated |
| Planting date | Establishes cycle timing |
| Harvest date | Measures actual days to harvest |
| Planted quantity / area | Provides forecast denominator |
| Harvested quantity | Core production actual |
| Saleable quantity | Separates production from marketable output |
| Loss / rejection quantity | Produces actual loss rate |
| Unit / package definition | Prevents unit ambiguity |
| Realized selling price | Replaces planning price |
| Buyer / channel | Explains price differences |
| Gross sales | Reconciles physical and financial records |
| Evidence / reviewer | Supports MRV and public reporting |

## Risk and uncertainty register

| Variable | Current assumption | Why it can change |
| --- | --- | --- |
| **Crop loss** | 15% baseline | Weather, pests, disease, establishment, handling, irrigation, labor |
| **Lettuce cycles** | 5/year | Variety, weather, bed turnaround, labor, soil management |
| **Market price** | Fixed planning prices | Season, quality, buyer, channel, certification, supply/demand |
| **Passion-fruit yield** | 100 gross fruits/plant/year | Establishment, disease, vine health, season |
| **Coconut yield** | 75 gross units/tree/year at maturity | Tree age, health, climate, management |
| **Poultry output** | ~100 eggs/day | Flock age, nutrition, health, season, mortality |
| **Certification** | In progress | Review timeline and compliance requirements |
| **Market access** | Target channels documented | Buyer relationships and commercial agreements are not guaranteed |
| **Operating costs** | Not modeled here | Labor, water, transport, packaging, maintenance, certification and more |
| **Public-goods allocation** | 10% farm-model assumption | Conflicts with 40/40/20 ReFi Playbook documentation and needs reconciliation |
