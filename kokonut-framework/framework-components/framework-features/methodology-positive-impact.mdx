# Positive impact is an interpretation earned by evidence — not a label attached to a practice.

Kokonut farms are designed to create useful ecological, economic, social, and public value.

That intention matters.

It is not enough.

A farm can:

- use syntropic practices;
- plant native species;
- apply biochar;
- create jobs;
- host training;
- publish records;
- receive funding;
- create an EAS attestation;

and still need more evidence before claiming that soil health, biodiversity, livelihoods, food access, climate outcomes, or community well-being **improved because of the intervention**.

The Positive Impact Methodology exists to keep those stages separate.

> **Design for positive change → document the activity → measure what changed → review the evidence → interpret the outcome with its limits visible.**

## The impact claim ladder

The methodology uses four levels.

```mermaid
flowchart LR
    A["1. Alignment<br/>the design targets a value"] --> B["2. Activity<br/>the intervention happened"]
    B --> C["3. Measured outcome<br/>a change was recorded"]
    C --> D["4. Impact interpretation<br/>evidence supports a bounded conclusion"]
```

| Level | Question | Example | What is still missing |
| --- | --- | --- | --- |
| **1 — Alignment** | What positive change is the design intended to support? | Syntropic design is intended to support soil cover and biological diversity | No proof the activity occurred or produced the intended change |
| **2 — Activity** | What intervention actually happened? | Ground cover was maintained; biochar was applied; seedlings were propagated | Outcome still needs measurement |
| **3 — Measured outcome** | What changed during a defined period? | Ground-cover percentage increased; a harvest quantity was recorded; seedling survival was measured | Causality, durability, distribution, and broader impact may remain uncertain |
| **4 — Impact interpretation** | What does the evidence reasonably support? | Evidence supports a bounded conclusion about land condition, production, work, learning, or public benefit | Interpretation must still preserve limitations and alternative explanations |

<Info>
  Most overclaiming happens when documentation jumps directly from **alignment or activity** to **impact interpretation**.
</Info>

## Positive impact in Kokonut

Within this Framework, **positive impact** means:

> **A documented intervention is associated with a beneficial change that has been measured over a defined boundary and period, reviewed using an appropriate method, and interpreted with contribution, risk, uncertainty, and alternative explanations visible.**

That definition has several consequences.

A positive-impact statement should normally be able to answer:

- **WHAT** changed?
- **WHO** or what experienced the change?
- **HOW MUCH** changed, over what period?
- What did the intervention **CONTRIBUTE**?
- What **RISK**, uncertainty, bias, or downside remains?
- Did any **PUBLIC GOODS** or shared value actually reach beyond the immediate private transaction?
- What source record supports the statement?
- What baseline or comparison exists?
- Who reviewed the record?
- Is the conclusion broader than the evidence?

If those questions cannot yet be answered, use a narrower claim.

## The methodology in one flow

```mermaid
flowchart TD
    A["Farm baseline + Pillars of Value"] --> B["Outcome hypothesis"]
    B --> C["Regenerative / operational practice"]
    C --> D["Source observation or transaction"]
    D --> E["Structured record"]
    E --> F["Review lifecycle"]
    F --> G["Published evidence"]
    G --> H["Measured outcome / variance"]
    H --> I["Impact interpretation"]
    I --> J["Farm · partner · research · governance decision"]
    J --> K["Updated plan / hypothesis"]

    G --> L["Optional public attestation"]
    L --> I
```

The public attestation is intentionally **not** placed between the record and scientific truth.

It can improve provenance.

It does not determine the interpretation.

## 1. Soil & land condition

### Intervention examples

- maintain living or biomass cover;
- reduce unnecessary mechanical disturbance;
- retain living roots;
- apply compost, biochar, manure-derived or other biological inputs;
- manage erosion;
- improve irrigation or water handling;
- maintain perennial structure.

### Safe activity-level claims

- “Biochar was applied to the documented plot.”
- “Ground cover was maintained during the reporting period.”
- “The farm reduced a documented category of external input.”
- “The plot is managed using reduced-disturbance practices.”

### Stronger outcome claims require evidence

| Stronger claim | Useful evidence |
| --- | --- |
| Soil moisture improved | Baseline + repeated moisture measurements with comparable method/context |
| Erosion risk decreased | Before/after observations, cover measurement, runoff/erosion indicators |
| Soil fertility improved | Defined soil indicators, repeated testing, input context |
| External-input dependency decreased | Procurement and application records across comparable periods |
| Soil carbon increased | Appropriate carbon methodology, baseline, sampling, boundary, period, uncertainty, review |

<Warning>
  **Biochar, compost, cover crops, or syntropic design do not by themselves establish soil restoration or carbon sequestration.**
</Warning>

## 2. Biodiversity & habitat

### Intervention examples

- multi-species planting;
- agroforestry;
- native or at-risk species propagation;
- nursery operations;
- habitat structure;
- reduced bare soil;
- pollinator-oriented planting;
- survival and distribution programs.

### Evidence can progress from simple to stronger

| Evidence stage | Example |
| --- | --- |
| **Inventory** | Species / seedling list |
| **Implementation** | Planting, propagation, or distribution record |
| **Spatial evidence** | Plot, GPS, imagery, habitat location |
| **Repeated outcome** | Survival, abundance, repeat survey, habitat-use observation |
| **Interpretation** | Bounded conclusion about biodiversity or habitat condition |

Remote-sensing indices such as NDVI, NDRE, ReCI, and MSAVI can help describe vegetation patterns.

They do not directly prove biodiversity restoration.

### Conservation-status caution

Repository materials use terms such as:

- native;
- at-risk;
- endangered;
- critically threatened.

Those terms should not be treated as interchangeable.

External biodiversity reporting should verify conservation status **species by species** against the appropriate authoritative source.

## 3. Production & resource cycling

A regenerative farm still has to operate as a farm.

Positive-impact methodology should therefore include:

- planted area and quantity;
- harvest;
- losses/rejections;
- realized selling price;
- inputs;
- labor;
- water;
- transport;
- recurring costs;
- resource reuse;
- waste/material flows.

### Circularity is a hypothesis until the loop is recorded

For example:

```mermaid
flowchart LR
    A["Crop / poultry activity"] --> B["Biomass · manure · residues"]
    B --> C["Processing / reuse"]
    C --> D["Farm input"]
    D --> E["Production"]
    E --> F["Actual yield + cost + resource records"]
    F --> G["Was dependency reduced?"]
```

A farm can intend to create a circular loop without fully closing it.

To claim that a practice reduced dependency or improved efficiency, compare:

- external inputs before/after;
- internally reused materials;
- labor required;
- cost;
- yield/quality;
- losses;
- any new risks created.

### Forecast remains separate from actual

> **A modeled crop yield, price, or revenue is not a positive-impact outcome.**

Use actual harvest and financial records to test the production hypothesis.

## 4. People & community value

Community value cannot be inferred from good intentions.

### Activity-level evidence can include

- job/role records;
- training sessions;
- attendance;
- public-space use;
- seedling distribution;
- food sales/distribution;
- partnership activity;
- open documentation;
- public-benefit expenditures.

### Stronger claims require stronger evidence

| Claim | Additional evidence needed |
| --- | --- |
| “Jobs were created” | Role, dates, status, responsible employer/operator |
| “Decent work improved” | Compensation, safety, duration, working conditions, worker evidence |
| “Training increased skills” | Participation plus learning/competency evidence |
| “Food access improved” | Distribution, affordability/access, target population, period |
| “Poverty decreased” | Household/income/beneficiary evidence appropriate to the claim |
| “Gender equality improved” | Participation, income, decision power, opportunity, distribution data beyond women-led ownership |
| “Public goods were delivered” | Approved arrangement, actual delivery/transfer, use/access records |

<Info>
  **Women-led ownership is a documented characteristic. It is not by itself evidence that wider gender inequality decreased.**
</Info>

## 5. Evidence, learning & accountability

This pathway makes the other four more inspectable.

It includes:

- source records;
- provenance;
- timestamps;
- methods;
- reviewers;
- lifecycle status;
- publication;
- evidence pointers;
- reports;
- optional attestations;
- forecast-vs-actual variance;
- revised assumptions.

The durable MRV sequence is:

> **observe → structure → review → publish → attest when useful → interpret**

Not every record needs:

- IPFS;
- Filecoin;
- EAS;
- an on-chain transaction.

Use those tools when durable public provenance materially improves the claim or governance process.

## Evidence maturity

A positive-impact methodology needs more than a single “verified / not verified” flag.

| Evidence maturity | Meaning |
| --- | --- |
| **Planned** | Method or evidence is defined before execution |
| **Observed** | A source event, condition, or transaction was recorded |
| **Measured** | A quantity or defined indicator was captured |
| **Reviewed** | An authorized reviewer/process checked the record |
| **Published** | The record can be used in governed downstream surfaces |
| **Attested** | A signed provenance statement exists where useful |
| **Interpreted** | A method/context supports a bounded conclusion |

<Note>
  Kokonut Intelligence's internal **Verified** workflow state belongs inside **Reviewed** here. It means authorized internal review, not scientific certification, regulatory approval, third-party audit, or environmental-credit eligibility.
</Note>

## Minimum impact-claim packet

For a material positive-impact statement, record at least:

| Field | Requirement |
| --- | --- |
| **Claim** | What exactly is being asserted? |
| **Claim level** | Alignment, activity, measured outcome, or impact interpretation? |
| **Farm / boundary** | Which farm, plot, stakeholder group, ecosystem, or system? |
| **Baseline** | What was the starting condition when relevant? |
| **Intervention** | What action is hypothesized to contribute? |
| **Metric / indicator** | What was observed or measured? |
| **Method** | How was it measured/calculated? |
| **Reporting period** | What dates does it cover? |
| **Actual / forecast** | Is this real observed performance or a model? |
| **Source** | What record or dataset supports it? |
| **Record status** | Draft, submitted, verified/rejected, published? |
| **Reviewer** | Who or what authorized the review? |
| **Contribution context** | What else may have caused the outcome? |
| **Risk / uncertainty** | What can weaken or reverse the interpretation? |
| **Evidence pointer** | Hub record, dataset, file, CID, attestation, report? |
| **Next evidence** | What would strengthen or falsify the claim? |

This packet can support:

- SDG interpretation;
- Pillars of Value analysis;
- 8 Forms of Capital reporting;
- EBF / CRISP work;
- grants;
- partner reports;
- research;
- governance review.

## Contribution and causality

Positive impact is stronger than documenting that an activity happened.

A credible interpretation asks:

- What was the baseline?
- What changed?
- Did the intervention occur before the change?
- Were measurements comparable?
- What other factors changed?
- What role did weather play?
- What role did markets, partners, policy, or community activity play?
- Would some change likely have happened anyway?
- Is the conclusion local to this plot/group/period, or being generalized too far?

This does not require pretending every farm study is a randomized experiment.

It does require matching the **strength of the language to the strength of the evidence**.

### Example

Too strong:

> “Syntropic farming restored Adelphi's biodiversity.”

Better at activity level:

> “Adelphi operates two documented syntropic plots and maintains nursery/agroforestry species relevant to biodiversity objectives.”

Potential stronger future interpretation:

> “Across **[defined plots]** from **[baseline period]** to **[reporting period]**, **[defined biodiversity indicator]** changed by **[measured amount]** under **[documented management]**. The interpretation is limited by **[weather / sampling / comparison / attribution constraints]**.”

## Risk belongs inside the impact claim

An impact claim can weaken or reverse.

Examples:

| Impact area | Persistence / reversal risk |
| --- | --- |
| Soil | Later disturbance, erosion, drought, input changes |
| Biodiversity | Mortality, habitat change, invasive pressure, management change |
| Jobs | Seasonality, funding loss, farm economics |
| Training | No retention or practical use of skills |
| Public goods | Funding assumptions fail; program stops |
| Open data | Stale, incomplete, inaccessible, or privacy-inappropriate records |
| Carbon | Reversal, boundary, permanence, leakage, methodology failure |

That is why the Pillars include **RISK**.

> **A positive outcome with high reversal risk should not be reported as if it were permanent.**

## Interpretation layers

Kokonut uses several frameworks that can sit **above** the evidence.

| Layer | Function | Does not automatically provide |
| --- | --- | --- |
| **Pillars of Value** | Structures WHAT, WHO, HOW MUCH, CONTRIBUTION, RISK, PUBLIC GOODS | Impact score or funding verdict |
| **8 Forms of Capital** | Categorizes types of value | Common unit of measurement |
| **SDGs** | Maps evidence to development goals | UN certification or proof of contribution |
| **EBF** | Organizes ecological-benefit interpretation | External ecological certification |
| **CRISP** | Supports risk analysis | Elimination of project risk |
| **Impact Calculator** | Structures scenario/evidence readiness | Measured outcomes |
| **Kokonut Intelligence** | Stores, reviews, analyzes, reports, and supports attestations | Replacement for methodology |

These layers should consume evidence.

They should not manufacture it.

## Public records and attestations

### Publication

A published record means the record is usable in the relevant downstream surface.

It does not mean the record is independently certified.

### EAS

An EAS attestation can help establish:

- who signed;
- when;
- schema;
- reference/evidence pointer;
- claim provenance.

It cannot establish by itself:

- that the measurement was methodologically sound;
- that the source was truthful;
- that causality was demonstrated;
- that a carbon quantity is valid;
- that biodiversity improved;
- that an SDG outcome occurred.

### IPFS / Filecoin

Content-addressed storage can help preserve evidence artifacts.

It is not required for every record.

And content addressing proves file identity/integrity—not the truth of the file's contents.

## Positive-impact reporting cadence

Impact should be interpreted over reporting periods, not as a permanent farm badge.

A periodic review should reconcile:

1. baseline;
2. planned intervention;
3. what was actually implemented;
4. actual production / finance / work / ecology records;
5. data quality and missing evidence;
6. risk events;
7. forecast variance;
8. stakeholder distribution;
9. Pillars of Value;
10. SDG / EBF / CRISP interpretation where appropriate;
11. unresolved uncertainty;
12. next-period evidence plan.

### A report should distinguish

- **documented state**;
- **forecast / target**;
- **implemented activity**;
- **measurement / actual**;
- **derived indicator**;
- **reviewed / published record**;
- **attestation**;
- **impact interpretation**.

Do not compress them into one “impact achieved” column.

## What software and AI can do

Kokonut Intelligence and AI agents can support the methodology by:

- checking record completeness;
- classifying claim/evidence maturity;
- comparing forecast vs. actual;
- calculating documented indicators;
- flagging missing baselines;
- identifying stale records;
- assembling evidence packets;
- drafting Pillars / SDG / EBF interpretations;
- surfacing contradictory claims;
- routing records for review.

They should not independently:

- certify positive impact;
- declare regulatory compliance;
- validate carbon-credit eligibility;
- decide scientific causality;
- conceal uncertainty;
- rewrite failed outcomes as successful ones;
- publish high-impact conclusions without the required human/domain review.

<Info>
  **Automation should make evidence easier to inspect—not make weak claims easier to scale.**
</Info>

## Common failure modes

| Failure mode | Better practice |
| --- | --- |
| “The farm uses regenerative practices, therefore it has positive impact.” | Report the practices first; measure outcomes separately |
| “The record is Verified, so the science is verified.” | Treat Verified as internal workflow review only |
| “EAS proves the claim.” | Use EAS for provenance; evaluate the underlying method/evidence separately |
| “The dashboard shows it, so it is current.” | Check source, record status, reporting period, freshness |
| “NDVI increased, therefore biodiversity improved.” | Treat NDVI as a vegetation indicator; use biodiversity-specific evidence for biodiversity claims |
| “Seven jobs means poverty decreased.” | Report seven documented jobs; measure livelihood outcomes separately |
| “Women-led means gender equality improved.” | Report women-led ownership/operation; measure broader outcomes separately |
| “Biochar means carbon sequestration was verified.” | Use the applicable carbon methodology before quantifying/crediting carbon |
| “10% public goods means 10% was distributed.” | Separate modeled, approved, transferred, and used amounts |
| “The DAO funded it, so impact was validated.” | Funding authorization and impact evidence are different |
| “The farm improved because the intervention existed.” | Examine baseline, timing, alternative explanations, and contribution |
| “One successful farm proves the Framework scales.” | Treat Terra Viva and future farms as additional replication tests |
